## التثبيت: النسخ اليدوي (دقيقة واحدة)

> **عندك إصدار سابق من التعريب؟** نفس الخطوات: استبدل الملفات بالجديدة مباشرة.

### 1) حمّل الملف

حمّل الملف المضغوط `DarkestDungeon2-Arabic.zip` (7.3 ميجابايت) وفك الضغط عنه:

<div align="center">

### 2) افتح مجلد اللعبة

أغلق اللعبة. في Steam: اضغط بزر الفأرة **الأيمن** على اللعبة في المكتبة ← **Manage** ← **Browse local files**.

### 3) انسخ المجلد

انسخ المجلد `Darkest Dungeon II_Data` من الملف المضغوط إلى مجلد اللعبة، واختر **استبدال الملفات / Replace**.

يستبدل التعريب ملفين فقط من ملفات اللعبة (`IronCrown.dll` و`Unity.TextMeshPro.dll` في `Darkest Dungeon II_Data/Managed`)،
وكل الملفات الأخرى جديدة تضاف إلى جانب ملفات اللعبة.

## كيف أزيل التعريب؟

1. من Steam: زر الفأرة الأيمن على اللعبة ← **Properties** ← **Installed Files** ← **Verify integrity of game files**
   (يعيد الملفين الأصليين).
2. احذف من مجلد اللعبة: `Darkest Dungeon II_Data/Managed/DD2Arabic.dll`، والمجلد `Darkest Dungeon II_Data/StreamingAssets/Arabic`،
   وملفات `ar.po` الأربعة، والمجلدين `arabic_language` في `Localization/Poedit` و`Localization/Sources`.

## English

A complete, unofficial Arabic translation of **Darkest Dungeon II** (Steam, PC): the base game, the Catacombs and
Dul Cru DLCs, and Kingdoms mode. Right-to-left text with joined letters; voices stay in English.

**Install:** close the game, download `DarkestDungeon2-Arabic.zip`, copy the `Darkest Dungeon II_Data` folder from it
into the game folder (Steam → right-click the game → Manage → Browse local files) and choose **Replace**. In the game:
Options → Game → Language → «العربية».

Made for Steam build 24911282. Two game files are replaced (`IronCrown.dll`, `Unity.TextMeshPro.dll`); Steam's
"Verify integrity of game files" restores them and removes the translation's effect.

Translation and localization: **Abdullah Hadi**. Unofficial fan translation, not affiliated with the developer or the
publisher. Fonts: Almarai and Aref Ruqaa (SIL Open Font License).
